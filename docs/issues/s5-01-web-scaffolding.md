## Goal
An empty React + TypeScript app with the approved look (both themes, Dock navigation), typed API
calls generated from the server, tests, and a CI job.

## Scope
- `web/`: Vite + React + TypeScript, React Router, TanStack Query (refresh every 5 minutes and on tab
  focus)
- API types generated by `openapi-typescript` from the server's OpenAPI description; `npm run check`
  fails if they are out of date
- Vitest + React Testing Library + a mocked API (MSW)
- design tokens as CSS variables: light "Quiet Ledger" and dark "Signal Desk" exactly as in
  `docs/design/prototypes/`; theme Windows / Light / Dark remembered in `localStorage`
- the Dock (React Bits) recoloured to the tokens, labels on hover, no badges;
  `prefers-reduced-motion` stops all motion
- a 401 anywhere redirects to `/login`
- `ci.yml`: the `web` job (Node 20, `npm ci`, `npm run check`)
- design work goes through the ui-ux-designer agent, as agreed

## Done when
- [ ] `npm run dev` shows an empty page per route with the Dock, in both themes
- [ ] `npm run check` runs types, tests and the API-types freshness check; CI green (3 jobs)

## How to test
```
cd web
npm ci
npm run check
npm run dev
```

## Learning
TypeScript basics; components; generated types from an API contract; mocking an API in tests.
