# Listen

A Windows voice assistant (`agent/`), with a FastAPI server (`server/`, stage 4) and a React web app
(`web/`, stage 5).

- **Design**: `docs/specs/2026-10-19-listen-design.md` is the source of truth.
- **Work**: every change belongs to an issue file in `docs/issues/`; read `docs/issues/README.md`
  before starting one. Progress and what is ready: `docs/roadmap.md`.
- **Commands**: `agent/README.md` (uv, tests, lint), `docs/cheatsheet.md`, `docs/gh-cheatsheet.md`
  (GitHub CLI and PowerShell quoting).
- **Review**: `CODING_STANDARDS.md`.
- **Authorship**: commits and PRs carry the owner's name only, with no co-author or tool trailers.
